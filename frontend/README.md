# 🎨 SecureGuard AI — Frontend Dashboard (React + Vite)

The frontend application for **SecureGuard AI** is built using **React 18**, **Vite 5**, **Tailwind CSS**, and **Recharts**.

---

## ⚙️ Features

- **Fraud Analytics & Risk Dashboard**: Visualizes high-level KPIs, fraud trends, channel breakdown, and suspicious alerts.
- **Fraud Detection Simulator**: Interactive lab for testing individual transaction payloads and observing ML scores + AI explainability.
- **AI Key Configuration Modal**: On-screen modal enabling users to configure NVIDIA NIM or Google Gemini API keys dynamically.
- **Responsive & Dark Mode UI**: Optimized for desktop and mobile displays with sleek glassmorphism aesthetic.

---

## 🏃 Running the Frontend

1. Navigate to `frontend`:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. App running on: **`http://localhost:5173`**.
